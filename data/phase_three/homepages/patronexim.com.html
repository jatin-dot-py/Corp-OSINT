Components of Drugs

All drugs contain two parts:
• API
• Excipient – These are chemically inactive substances that help deliver the API to the system. Eg. lactose, mineral oil, etc.

Intermediate is the chemical substance that is in the process of becoming an API from a raw material. Sometimes, many intermediates are produced before the final API is manufactured.
